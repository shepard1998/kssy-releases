# KSSy · versiones

Instaladores de **KSSy**, la app de juegos para 2 jugadores, y los archivos que usa su actualizador (`latest.json` y las firmas `.sig`).

Este repositorio no contiene código: solo las versiones publicadas.

## Instalar

Descarga el `KSSy_X.Y.Z_x64-setup.exe` de la [última versión](../../releases/latest) y ejecútalo. Como no está firmado con certificado de Windows, SmartScreen avisa la primera vez: "Más información" → "Ejecutar de todas formas".

Una vez instalada, la app busca versiones nuevas sola y se actualiza con un clic.
